# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x.x   | :white_check_mark: |

## Privacy & Security Model

The quick evaluation tools in this project operate under a **zero-knowledge, client-side only** architecture:
- All image rendering, JPEG recompression, pixel difference matrices, and EXIF parsing are computed in the local browser sandbox.
- No image bytes or user identifiable telemetry are sent to remote servers during quick analysis.

## Reporting a Vulnerability

If you discover a security vulnerability or potential privacy issue in this repository:

1. **Do not** report security vulnerabilities through public GitHub issues.
2. Please reach out via email to **abhrankan@gmail.com** with details of the vulnerability, reproduction steps, and expected impact.
3. You will receive an acknowledgment within 48 hours.
